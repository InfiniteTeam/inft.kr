## 1. 콘셉트 — Pearl Light

새벽빛이 유리를 통과하며 흩어지는 순간. 화면 대부분은 비워 두고, 빛은 한 곳(히어로의 유리 로고)에만 모읍니다.

- **절제**: 화려한 효과는 히어로 오브젝트 하나뿐입니다. 나머지는 타이포그래피와 여백으로 이야기합니다.
- **진주빛**: 흰색 대신 아주 옅은 회백색(porcelain) 바탕에, 홀로그램 색은 오브젝트와 빛의 반사에만 씁니다.
- **브랜드 연결**: 홀로그램 스펙트럼의 시작점은 Infinite Mint(#00CC99)와 Turquoise(#33CCCC)입니다. 민트에서 라일락, 로즈로 이어지는 진주빛 스펙트럼을 씁니다.

## 3. 타이포그래피

- **Pretendard Variable** — 모든 본문/UI. 한글 자간 `-0.02em` 기준, 제목은 더 좁게(`-0.035em`).
- **KORAIL Condensed (코레일 장체)** — 세로로 긴 디스플레이 서체. 메인 슬로건, 큰 숫자에만 씁니다. (눈누 `@noonnu/korail-condensed-regular`)
- 숫자는 `tabular-nums`, 한글 제목은 `word-break: keep-all` + `text-wrap: balance`.

| 역할 | 서체 | 크기 |
| --- | --- | --- |
| 슬로건 | KORAIL Condensed | `clamp(64px, 11.5vw, 184px)` / 0.92 |
| 섹션 제목 | Pretendard 650 | `clamp(34px, 4.6vw, 64px)` / 1.12 |
| 리드 문단 | Pretendard 600 | `clamp(26px, 3.4vw, 48px)` / 1.3 |
| 본문 | Pretendard 450 | 17px / 1.65 |
| 라벨 | Pretendard 600 | 13px, 영문 대문자는 `0.08em` |

## 4. 레이아웃

- 최대 폭 1240px, 좌우 여백 `clamp(20px, 5vw, 64px)`, 12열 그리드.
- 섹션 간 간격은 넉넉하게 (`clamp(120px, 16vw, 220px)`).
- 정보 구조
  - `/` 히어로 → 소개 문장 → 숫자 → 프로젝트 → 걸어온 길 → 팀 → 합류 CTA
  - `/about` 미션, 팀원 전체, 연혁 전체
  - `/projects` 프로젝트 상세
  - `/brand` 로고, 컬러, 사용 규정, 로고 다운로드
  - `/privacy` 개인정보 처리방침

## 5. 히어로 3D

- 로고 SVG 패스를 그대로 압출(extrude)하고 모서리를 둥글게 깎은 유리 오브젝트.
- 재질: 투과(transmission) + 박막 간섭(iridescence) + 약한 색수차. 뒤의 진주빛 배경이 굴절되어 보입니다.
- 배경: 셰이더로 그린 아주 느린 파스텔 흐름. 히어로 아래쪽에서 페이지 바탕색으로 자연스럽게 이어집니다.
- 인터랙션
  - 커서를 따라 천천히 기울어짐
  - 드래그하면 관성을 가지고 회전
  - 클릭하면 박막 색이 한 번 훑고 지나감
  - 스크롤하면 위로 떠오르며 회전
- 화면 밖에서는 렌더링 중지, `prefers-reduced-motion`이면 정지 상태, WebGL이 없으면 SVG 홀로그램으로 대체.

## 6. 모션

- 이징 `cubic-bezier(.22, 1, .36, 1)`, 등장 700–900ms, 이동 거리 16–24px.
- 등장 애니메이션은 한 번만. 스크롤 연동은 소개 문장(단어 단위 밝아짐)과 히어로 오브젝트에만.
- 호버: 카드 위 커서 위치를 따라 아주 옅은 홀로그램 광택.
