# inft.kr 디자인 노트 (v2)

> 무한한 미래를 만들어 갑니다

v2는 [Hallmark](https://github.com/Nutlope/hallmark)의 규칙(Floor, gates)을 기준으로 다시 만들었습니다. 스탬프는 `src/app/globals.scss` 맨 위에 있습니다.

## 아이디어

**로고가 유일한 광원.** 어두운 화면에서 색은 홀로그램 유리로 된 iN 심볼 하나에서만 나옵니다. 나머지 화면은 잉크와 회색만 씁니다.

## 레이아웃

- 히어로: 로고, 슬로건, 한 문장, 동작 둘을 **하나의 세로축**에 쌓습니다 (요청에 따른 가운데 정렬).
- 히어로 아래의 섹션 제목은 전부 **1열 왼쪽 끝**에 맞춥니다.
- 홈 순서: 히어로 → 프로젝트(벤토) → 소개 문장과 숫자 셋 → 연혁(행) → 팀(그리드) → 합류 띠 → 푸터(슬로건)
- 내비게이션: 가운데 떠 있는 알약. 브랜드 페이지는 푸터에서만 엽니다.

## 컬러 (OKLCH, 다크 전용)

| 토큰                              | 값                     | 용도                                        |
| --------------------------------- | ---------------------- | ------------------------------------------- |
| `--color-paper`                   | `oklch(14% 0.012 265)` | 바탕                                        |
| `--color-paper-2` / `-3`          | `17.5%` / `21%`        | 띠, 카드 (어두운 화면에선 위로 갈수록 밝게) |
| `--color-ink`                     | `oklch(95% 0.008 265)` | 제목, 주 버튼 바탕                          |
| `--color-ink-2` / `--color-muted` | `82%` / `68%`          | 본문 / 보조                                 |
| `--color-rule` / `-soft`          | `30%` / `23%`          | 헤어라인                                    |
| `--color-accent`                  | `oklch(84% 0.12 170)`  | Infinite Mint에서 온 색. 포커스 링에만      |

홀로그램 색(`--holo-*`)은 로고와 그 대체 이미지에서만 씁니다.

## 서체

- **빈폴체** (`@noonnu/beanpoleot-m00`): 슬로건과 페이지 제목의 **한글에만**. `unicode-range`로 한글 음절과 자모만 맡기 때문에, 같은 문장 안의 영문과 숫자는 자동으로 Pretendard로 그려집니다.
- **Pretendard Variable**: 그 밖의 모든 글자와 영문, 숫자. 큰 숫자(통계, 연도, 404)도 Pretendard 650. 굵기는 400과 650 두 가지.

## 3D 로고

- 히어로는 화면을 덮는 셰이더 하나(`src/components/hero/glassShader.ts`)가 오로라와 유리 로고를 함께 그립니다.
- 로고는 메시가 아니라 거리장(SDF)을 레이마칭합니다. 로고 애니메이션 Lottie의 움직임과 이징을 그대로 옮겨(`morph.ts`), "I" 한 줄이 기둥 둘과 대각선으로 펼쳐지고 점이 왼쪽 기둥에서 솟아올랐다가 다시 가라앉고 접힙니다. 머무는 시간만 바꿔 iN은 약 5초, 접힌 "I"는 약 1초 머뭅니다(10초 고리).
- 막대를 합치지 않고 깎아 냅니다. 왼쪽 기둥 끝부터 오른쪽 기둥 끝까지 이르는 둥근 사각형 하나에서 대각선 위쪽 골짜기, 아래쪽 골짜기, 점을 둘러싼 큰 원을 도려냅니다. 합친 막대 사이의 이음새가 처음부터 없어서 표면이 한 덩어리로 매끄럽고, 큰 원은 두 막대를 한 번에 잘라 먹으며, Lottie의 트랙매트가 가리던 대각선 끝도 저절로 가려집니다. 모서리는 원호로 둥글려(바깥 40, 안쪽 18, 큰 원 끝 30, 대각선 발끝 16) 다 펼쳐진 모양이 SVG 로고 윤곽과 맞습니다.
- 유리는 같은 셰이더 안에서 뒤의 오로라를 직접 굴절시킵니다. 들어가며 한 번, 안을 지나 나오며 한 번 꺾이고, 나올 때 빨강, 초록, 파랑이 조금씩 다르게 꺾여(분산) 가장자리에 무지개 테가 생깁니다. 겉면에는 자리마다 두께가 다른 박막 간섭이 반사광을 여러 색으로 가릅니다.
- 오로라는 띠 두 줄과 옅은 빛이 천천히 흐르며 초록, 청록, 보라, 분홍을 약 1분에 한 바퀴 돕니다. 캔버스 가장자리는 페이지 배경색(`--color-paper`을 브라우저가 칠한 값 그대로)이라 경계가 보이지 않습니다.
- 윤곽선은 셰이더가 화소 하나 폭으로 직접 부드럽게 덮고, 매 프레임 바뀌는 무작위 표본을 쓰지 않아 움직여도 자글거리지 않습니다.
- 인터랙션: 커서를 따라 기울기, 드래그와 관성, 누르면 한 바퀴와 함께 박막 색이 크게 흐름, 스크롤하면 회전.
- 화면 밖에서는 렌더링을 멈추고, 모션 줄이기 설정이면 iN에 멈춰 있고, 성능이 떨어지면 해상도와 품질을 낮추며, WebGL이 없으면 SVG로 대체합니다.

## 나타나는 움직임

- 페이지를 옮기거나 스크롤해서 블록(섹션 제목, 카드, 목록 줄)이 화면에 들어오면 위에서 16px 내려오며 0.76초 동안 나타납니다. 한 번에 들어온 것들은 70ms씩 차례로.
- 숨김은 `<head>`의 짧은 스크립트가 `data-reveal="on"`을 붙였을 때만 걸립니다. 모션 줄이기 설정이거나 스크립트가 3초 안에 시작하지 못하면 처음부터 그대로 보입니다.
- 쓰는 곳에는 `data-reveal` 속성만 붙이면 됩니다(`src/components/site/Reveal.tsx`).

## 지키는 규칙 (Hallmark Floor에서)

- 제목 위 작은 라벨(eyebrow), `A · B · C` 같은 가운뎃점 나열, 장식용 상태 점을 쓰지 않습니다.
- 예외 둘(요청): 사이트 밖으로 나가는 링크와 버튼 끝에만 작은 우상향 화살표를 붙이고, 히어로 슬로건 아래 "SINCE 2018" 한 줄만 대문자 자간을 씁니다.
- 색, 서체, 여백은 `:root` 토큰으로만 씁니다. 브랜드 컬러 칩만 예외(페이지 데이터 자체가 색이기 때문).
- 엠 대시, 지어낸 숫자나 문구를 쓰지 않습니다. 숫자는 `src/data`에 있는 것만 씁니다.
- 움직임은 `transform`과 `opacity`만, 모두 `prefers-reduced-motion` 대체가 있습니다.
